# NoVA Eats — IT 301 Final Project

A guide to my favorite places to eat in Northern Virginia, for people new to or visiting the area.

## Pages
- `index.html` — Home: photo banner, about me, Big Five cards
- `kabob-express.html`, `melt.html`, `sushi-on.html`, `sweetwater.html`, `mccormick.html` — one review per restaurant

Every review page has the same layout: location + description, photo with score,
The vibe, What to order, a quote, The verdict, and a Quick facts box.

## Where the requirements are
- **Shared CSS:** `css/shared.css` is used by every page; each page also has its own small CSS file
- **Media queries:** at the bottom of every CSS file (comment: "media queries")
- **Two fonts:** Roboto for headings, Open Sans for body text
- **Positioning:** sticky header, fixed "Top" button, relative + absolute score badges, absolute photo caption on Sushi On
- **Form with validation:** email signup in the footer (`required` + `type="email"`)
- **External links:** official restaurant sites, Google Maps, Wikipedia
- **Images:** all photos are mine and have alt text
